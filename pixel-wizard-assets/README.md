# Pixel Wizard Castle Defense

Phaser-ready transparent sprite sheets plus a Next.js client component.

## Sheets
- Wizard idle: 4 frames, 64x64
- Wizard cast: 4 frames, 64x64
- Wizard game over: 3 frames, 64x64
- Goblin: 4x4 grid, 48x48 cells
- Slime, skeleton wraith, shadow bat: 3x4 grids, 48x48 cells
- Enemy rows: enter, idle, attack, death

## Install
```bash
npm i phaser
```
Copy the `assets` folder, `WizardDefenseScene.js`, and `next-phaser-client.jsx` into your Next.js app. Render the client component from a page. Press SPACE to cast and G to trigger game over in the sample.
